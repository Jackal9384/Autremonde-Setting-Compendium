## 本設定集について

本設定集は、異世界ファンタジー世界**ムネ**の世界観を網羅的にまとめた公開設定資料です。地理・文明・種族・魔法・信仰・諸国・社会・魔物・冒険者まで、世界の全容を収録しています。

読者およびクリエイター向けの公開設定であり、**物語のネタバレは含みません**。

## 世界概観

世界**ムネ**は三つの大陸からなり、陸橋と航路で結ばれています。

- **テール大陸（主大陸）**：中央に位置し、エルフの故郷。現在はオレーグ帝国が独占。
- **ノール大陸（北境大陸）**：北に位置し、人類の故郷。西部六国が守る。
- **スダ大陸（魔大陸）**：南西に位置し、魔族とドワーフの故郷。北から南へ三国が並ぶ。
- **南方海域**：細長い長島で、純血エルフの王国イプレガリアがある。

## おすすめの読み方

- **世界を手早く把握**：第一章『世界与地理』と第三章『种族』。
- **独自設定を深掘り**：第五章『魔法体系』と第四章『疾病与遗传』が本作の独創性の核心。
- **各国を知る**：第七章『诸国志』に十三か国の完全な資料を収録。
- **細部・風俗**：第八章・第九章・第十章で社会・魔物・亜人を詳述。
