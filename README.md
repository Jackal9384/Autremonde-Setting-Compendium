## 关于本设定集

本设定集整理了架空奇幻世界"穆涅"的完整世界观设定，供读者与创作者参考。内容覆盖地理、文明、种族、魔法、信仰、诸国、社会、魔物与冒险者等全部层面。

本设定集为公开设定，不含作品剧情内容。

## 世界概览

世界名**穆涅**，陆地主要分为三块大陆，由路桥或航路彼此连通。

- **泰尔大陆（主大陆）**：居中，精灵的故土，如今为奥列格帝国独占。
- **诺尔大陆（北境大陆）**：居北，人类的故土，西部六国据守。
- **叙德大陆（魔大陆）**：居西南，魔族与矮人的故土，三国由北而南分布。
- **南方海域**：细条状长形大岛，纯血精灵王国伊普雷加利亚的领地。

- **快速了解世界**：先读第一章《世界与地理》与第三章《种族》。

- **配角与细节**：第八、九、十章为社会生态、魔物与亚人详设。
