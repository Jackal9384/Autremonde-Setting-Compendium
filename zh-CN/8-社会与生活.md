# 第八章 社会与生活

> 圣历 1810 年

## 一、货币与物价

### 币制基准

世界采用**贵金属本位**：各国自行铸币，金币、银币、铜币三级，价值以贵金属含量衡量。各国铸币成色不一，跨国贸易按贵金属含量折算，商人与钱庄（以艾西尼亚的汇票与清算行最为发达）负责折价。银币为日常大宗（平民生活、商路买卖），金币为大宗交易与国库存量，铜币为市井零钱。

**成色标杆**：奥列格帝国金路易为大陆流通最广、最受信任的货币，各国商人习惯以"奥列格金"为估价基准。

### 折算与购买力

**折算基准**（以奥列格货币为基准）：1 金路易 = 10 银埃居 = 1000 铜苏（各国内部十进位或百进位制式因国而异，跨国按金银含量折算）。

**购买力参考**（以奥列格腹地平价计）：
- 1 铜苏：一篮面包或一壶粗酒
- 1 银埃居：一个普通家庭数日口粮，或一名工匠数日工钱
- 1 金路易：一个农民家庭数月开销，或一件精良武器
- 魔大陆（叙德）物价高昂：同量货币在奥弗涅外购买力显著缩水
- 战乱地区（如达勒卡利亚边区）：战乱+连年加税+赔款压榨之地，物价为奥列格腹地3-4倍，铜苏几乎不值钱，银埃居才能当钱用，底层民众在饿死线上挣扎

### 贸易结算习惯

- 大宗跨国贸易（商路、粮食、矿产、军火）：以奥列格金路易或艾西尼亚金达克特计价结算，艾西尼亚钱庄签发汇票，是西陆信用体系的中心。
- 边贸与零散：直接称重金块/银锭或以物易物，商路集市上常见"称银"。
- 魔法材料与稀有品：纳穆尔、奎尔松交易中，常以实物（魔源体、精矿）折算替代货币。
- 战乱与盗匪地带：只认实物与称重贵金属，纸币与汇票无人认。

## 二、交通与驿道

### 维拉时代的遗产：车同轨，书同文

七贤者"通路之墨衡"（地球·秦）为维拉帝国制定了统一标准：

- **车同轨**：全国道路统一轨距，马车轮距标准化，任何车辆可在任何驿道行驶。
- **书同文**：帝国统一文字（古精灵语通行文书体），公文驿传无障碍。
- **驿道树**：墨衡留下的魔法植物，沿驿道种植，根系固化路基、树冠提供荫蔽，兼有定位与传递简单讯息的用途。
- **石板路基**：驿道以石板铺设，风雨不侵，数百年不坏。
- **驿馆体系**：沿线设驿馆，提供食宿与换马，百里一驿。

### 崩溃后的现状（1810年）

**维拉遗产的衰落**：帝国崩溃后，驿道疏于维护，石板路基在无人养护处逐渐被杂草与泥土吞没，断头路比比皆是；驿道树枯死大半，仅存的路段仍嵌在农田与荒野之间，成为农夫耕田的田埂、旅人认路的地标；驿馆废弃，多数沦为废墟或盗匪巢穴。

**各国自行修复**：各国在继承的旧驿道基础上修补主干道，但标准不再统一——轨距、路况、关卡各自为政。车同轨的遗产只在旧驿道主体路段残留：新修道路各国自行其是，跨国的马车往往要在边境换轮或换车。

### 旅行方式

- **步行**：平民主流，日行20-30里。
- **骑马**：骑士/信使/富裕阶层，日行50-80里。
- **马车**：商旅与贵族，日行30-40里（旧驿道好路可更快）。
- **驮队**：山区（洪加利/奎尔松）与沙漠（松德高）主流，骆驼/驮马/骡。
- **船运**：两河、沿海、运河，大宗货运首选，成本最低。

### 旅行中的现实

- **通行证与关卡**：各国边境与国内要道设卡，验关文书（各国自行签发，跨国需多国文书）。
- **匪患**：废弃驿道与荒地是盗匪巢穴，商队护卫（佣兵/冒险者）需求由此而来。
- **驿馆与旅店**：奥列格官营驿馆、民间客栈、教会招待所并存。
- **路费参考**：骑马日耗（草料＋食宿）约1-2银埃居；马车出行（含车夫与马匹）日耗3-5银埃居；商队护卫每人每程1-3银埃居。

## 三、服饰与审美

### 审美总纲

- **泰尔大陆（奥列格）**：继承精灵审美——**黑发、蓝眼、黑眼为高贵象征**，肤白为贵族标志（不事劳作），精灵式深瞳是上流社会追捧的长相。
- **诺尔大陆（人类故土）**：主流推崇**金发碧眼的人类式审美**——人类本位文化的体现，与泰尔的精灵化审美形成对照；但**少部分上层家族**（受维拉千年余荫影响、或与精灵/七贤者后代联姻者）仍保留黑发蓝眼的"高贵审美"，以此标榜血统。
- **叙德大陆（魔大陆）**：魔族审美近于中东——浓眉深目、络腮胡为男性阳刚标志；矮人审美以体格敦实、须发浓密为美。

- **骑士**：板甲外罩纹章战袍。
- **神职人员**：圣公宗黑袍白领；主教紫红；教皇纯白。

- **平民**：粗布、皮革、木鞋或草鞋；颜色灰暗（染料昂贵，鲜艳色即有财力的标志）。

## 四、音乐艺术

### 宗教音乐

| 体系 | 音乐形式 |
|------|---------|
| 圣公宗（奥列格/诺尔主流） | 圣咏以人类通用语演唱，合唱与管风琴（魔法管风琴：以魔法阵驱动音色浑厚）；弥撒配乐庄严肃穆，旋律单声部为主 |
| 格雷米奥修会（精灵） | 古精灵语圣咏：无伴奏纯人声，多声部复调（精灵和声天赋极佳），仪式一字不改；传说某些圣咏本身即是失传的森林法系共鸣术 |
| 公理派 | 圣咏简化为赞美诗，会众齐唱，平易近人 |
| 归真教 | 每日五拜的召祷（宣礼），无音乐器乐，纯人声唤礼，声调高亢苍凉，在沙漠中回荡 |

### 宫廷音乐

- **奥列格**：继承维拉宫廷乐传统（精灵器乐），以竖琴、长笛、琉特琴为主，乐风优雅华丽。
- **伊普雷加利亚**：精灵古乐巅峰，弦乐（树琴，以古树纤维制弦）与风鸣笛，音乐被视为沟通森林之灵的仪式。
- **阿卡迪奥斯**：军乐发达——战鼓、号角、军歌；贵族圈流行组舞曲。
- **达勒卡利亚**：宫廷礼乐繁复（拜占庭式），以圣咏与宫廷合唱为主，器乐衰退。
- **纳穆尔**：魔法音乐中心——炼金乐器（魔法阵驱动的共鸣器）实验活跃，法师沙龙流行"音律炼成"（以声音调谐魔力）。

### 民间音乐

- **吟游诗人**：以歌谣传唱英雄故事、时事新闻与贵族八卦，是平民的信息来源。吟游诗人不受行会约束，各国态度宽松（除松德高：视为流窜者限制入城）。
- **酒馆乐手**：通俗小调、下流歌谣、舞曲。
- **劳动歌谣**：船歌（艾西尼亚/奥弗涅）、矿歌（洪加利/奎尔松）、麦收歌、行军歌。
- **婚礼与节庆乐**：圣元节、丰收礼等节日均有对应乐舞。

### 音乐与魔法

- 讼言派咒文本身具有"音乐性"：吟诵节奏与音调是施法的一部分（言灵塑形），故讼言派术师往往兼通音律。
- 森林法系吟唱（伊普雷加利亚）与圣咏同源：古精灵语的音律能引发魔力共鸣。
- 传闻存在"战歌法师"：以歌声凝聚士气类魔法，但史料无实证，多为传说。

## 五、民俗与传说

### 先民时代的民间记忆

迷宫与遗迹化为乡野怪谈：农夫相信迷宫入口会吃人，猎户流传着迷宫里埋着先民宝库的歌谣。

- **地下城的哭声**：封存于迷宫深处的造物在深夜发出哀嚎，夜行者途经遗迹时偶能听闻。
- **石人守门**：先民迷宫入口常有构造体守卫的传说，村民以此恐吓孩童不得靠近遗迹。

### 圣教民俗

- **圣元节**：神明诞辰，历法纪元起点，家家点灯祈福，灯火彻夜不熄。
- **圣贤节**：纪念七贤者降临，孩童扮作七贤者模样挨家讨要糖果。
- **丰收礼**：秋收后的感恩祭，祭粮仓、谢神明，乡村宴饮欢庆。
- **斋礼**：忏悔节，禁食数日以赎罪愆，教士宣讲节制之德。

### 归真教民俗

- **开斋宴**：斋月结束后的盛大宴席，家家备宴、互赠饮食。
- **朝圣归来**：朝圣者归乡时沿途撒圣水，乡人认为圣水可驱邪避祟。

### 龙的故事

- **屠龙勇士**：酒馆中最受欢迎的吹嘘题材，绝大多数屠龙故事只是酒徒的编造。
- **龙取祭品**：大河沿岸村庄流传的传说——鳄龙（沼龙）夜间拖走河边的牛，村民煞有介事地描述"龙选了祭品"。
- **家徽龙纹**：贵族家徽中常见龙纹，攀附"屠龙血统"或"驭龙血脉"以彰显门第。

### 职业民俗

- **风暴新娘**：水手的传说，风暴洋会收走最年轻的水手作"新娘"，出海前不得提及此事。
- **山神禁忌**：矿工的规矩，进矿不呼同伴全名，据称山神会记住名字把人留在矿里。
- **新手徽章**：冒险者的忌讳——新手徽章不能擦得太亮，太亮会被魔物"盯上"。

### 乡野禁忌

- **夜不呼名**：入夜后不在荒野呼唤熟人的名字，据说会招来不该来的东西。
- **门槛盐线**：农家在门槛撒盐线防"脏东西"进门，盐线被踩断视为不祥。
- **祭井**：井水干涸的村庄在井口供祭品，祈求先民时期遗留的"井中之物"放水。

### 婚俗

**圣公宗婚仪**（奥列格/诺尔主流）：婚前男方聘礼、女方嫁妆，双方家族谈妥后由教会公告三次（防重婚）。仪式在教堂举行：新娘白袍、新郎佩剑，神父主持，交换誓言与戒指，以圣水祝福。婚姻是宗教契约，一夫一妻，离婚极难（需教会特许）。贵族婚多为政治联姻，婚礼盛大、宴席数日。

**公理派婚仪**（维洛恩系/卡恩堡等地）：简朴，无神父也可由长辈主持，婚后可协议离异。

**归真教婚仪**（魔大陆）：婚前男方出聘礼（牲畜/钱财），女方家族同意后举行婚宴，不设教堂，教长或长辈证婚。

**精灵婚仪**（伊普雷加利亚）：古礼，树前结誓，以森林法系结界封存婚约，仪式以古精灵语念诵。

**平民婚俗**：无教堂费用，村中长老或游方神父见证，一餐宴席即礼成。

### 丧俗

**圣公宗葬礼**：临终告解→遗体净身、覆白布→教堂守灵一夜（蜡烛环绕）→葬入教会墓地，面东而葬（朝向圣城/日出），石质墓碑刻名与祷文；贵族葬于家族墓室或教堂地下。

**公理派葬礼**：简朴土葬，墓地不限教会，亲友悼念、撒土为礼。

**归真教葬礼**：遗体当日速葬（不隔夜），简单土葬，坟不立碑或立小石，悼念期数日，亲属黑衣。

**精灵葬礼**（伊普雷加利亚）：树葬或火葬，骨灰撒入森林，不立碑——亡者归于森林之灵。

**魔族葬俗**（松德高）：火葬为主，骨灰入陶瓮，置于家族祭坛；战死者就地葬于战场，立石为记。

**战乱葬俗**：乱葬坑、无名冢常见，村民以石堆或木十字为亡者立简易标记；瘟疫死者焚烧。

## 六、基本律法

### 律法源流

- **维拉法典（远古渊源）**：七贤者"法典之禹承"（地球·战国末期）为维拉帝国制定的第一部双族共遵成文法典，是现代诸国律法的共同母本。维拉崩溃后，法典随分裂散佚，各国各取所需地继承其条文。
- **教会法（圣教法）**：圣教教廷以《圣典》教义为纲制定的律法，管婚姻、继承、教会财产、异端审判——与世俗法并行。
- **习惯法（属地法）**：各地领主祖传判例与地方惯例，卡恩堡等封建国家以习惯法为主。
- **商业法（商事惯例）**：艾西尼亚、尤西斯坦等商业国以商会契约为准绳的商事裁判。

### 律法结构（各国普遍分层）

```
世俗法（王室/皇帝法）─┬─ 刑法（盗窃/伤人/杀人/叛乱）
                     ├─ 民法（土地/契约/债务/继承）
                     └─ 身份法（贵族/自由民/农奴/奴隶）
教会法（圣教法）─── 婚姻/继承/异端/神职
习惯法（属地法）─── 领主裁判权内的判例
商业法（商事法）─── 契约/票据/破产/海事
```

### 司法体系

- **王室法庭**：国王/皇帝直辖，审理重大案件与上诉（奥列格、阿卡迪奥斯完善）。
- **领主法庭**：领主在封地内的裁判权（卡恩堡近乎完整、纳穆尔公爵领地自治）。
- **教会法庭**：婚姻与信仰案件，异端审判庭（圣公宗可自行逮捕审讯判决）。
- **商事法庭**：艾西尼亚金秤议会下设，商人仲裁，契约优先。
- **决斗裁判与神判**：证据不足时通行——决斗（贵族/军人）、烙铁与沸水神判（平民）、宣誓洗罪。

### 刑罚体系

- **财产刑**：罚金（按罪行与身份分级）、没收财产。
- **身体刑**：鞭刑、烙刑、断肢（盗窃惯犯）、宫刑（达勒卡利亚宦官来源之一）。
- **自由刑**：枷号、监狱（多为关押待审或债务人）、劳役（矿山/军垦）。
- **死刑**：绞刑（平民）、斩首（贵族，更"体面"）、火刑（异端/女巫/纵火）、车裂与剥皮（奥列格针对叛乱者）。
- **流放**：流放荒原或矿山边区。

### 各国司法差异

| 国家 | 司法特征 |
|------|---------|
| 奥列格 | 王室法庭强、成文法为主（维拉法典＋圣公宗教会法）、异端审判活跃 |
| 阿卡迪奥斯 | 军法优先，军事法庭可审平民；刑法严苛 |
| 卡恩堡 | 领主法庭割据，同一行为相邻领地法律后果完全不同 |
| 艾西尼亚 | 商事法庭主导，契约至上，无奴隶制 |
| 尤西斯坦 | 商业契约逐步替代教会司法 |
| 达勒卡利亚 | 教会法庭主导，官位/司法权可买卖 |
| 纳穆尔 | 各公爵领地自治司法 |
| 洪加利 | 革命后立法，废除贵族特权但保留奴隶制（矿奴法） |
| 松德高 | 军事贵族（贝伊）法庭，习惯法＋归真教法 |
| 奎尔松 | 矮人城邦长老仲裁，锻造行业行会法 |
| 奥弗涅 | 王室法＋海事法 |
| 阿格若 | 教廷法，教区审判 |
| 伊普雷加利亚 | 森林法系结界法庭，古礼裁判 |

## 七、奴隶制度

### 总则

**除艾西尼亚外，奴隶制度在本世界全部合法**。各国制度框架高度雷同（同一套模子），仅在对奴隶的态度与蓄奴风气上存在少量区别。

### 各国蓄奴风气

**蓄奴风浓烈派**

| 国家 | 态度与风气 |
|------|-----------|
| 卡恩堡 | 蓄奴风气最盛：亚人养殖业是财政支柱，奴隶公开买卖、与牲畜同市，虐待寻常 |
| 松德高 | 蓄奴风浓厚：魔族视战俘为奴，奴隶充斥采石场与农田，视奴役他族为威权象征 |
| 奥列格 | 蓄奴风浓厚：奴隶以魔族、亚人为主（与歧视政策一致），人类奴隶多为债务奴；逃奴追捕极严 |
| 尤西斯坦 | 蓄奴风重：**圈地运动**——贵族与商人以合法手段圈占公有地，把自耕农逼成奴隶；同时**劫掠人口**充当奴隶 |
| 阿格若 | 与奥列格态度相近：教廷蓄奴，奴隶多为魔族、亚人，教堂奴被包装为"服侍神明"的善举 |

**蓄奴风一般/功能性派**

| 国家 | 态度与风气 |
|------|-----------|
| 阿卡迪奥斯 | 战俘奴最多：连年征战的直接产物，多用于军垦与军需生产；奴隶被视作战利品 |
| 洪加利 | 矿奴制度：革命后并未解放奴隶，矿山奴隶是资本家剥削的廉价劳力 |
| 奥弗涅 | 风气一般：奴隶多用于农田与商船，管理相对宽松 |
| 奎尔松 | 风气较淡：矮人很少蓄奴，奴隶多为魔族战俘，用于矿脉苦役 |

**风气渐衰/缓和派**

| 国家 | 态度与风气 |
|------|-----------|
| 达勒卡利亚 | 传统蓄奴国但风气渐衰：战败后主家多养不起奴，受艾西尼亚影响奴隶待遇相对宽松 |
| 纳穆尔 | 风气最淡：受艾西尼亚影响深，法律上奴隶待遇缓和、赎身容易 |

**无奴派**

| 国家 | 态度与风气 |
|------|-----------|
| 艾西尼亚 | 唯一废奴国，接纳逃亡奴隶，是解放灯塔 |
| 伊普雷加利亚 | 无奴隶制度：外族禁止定居，精灵不为奴 |

### 奴隶来源

- **战俘奴**：战争俘虏沦为奴隶，1793-1801年战争中的达勒卡利亚降民多有此命运。
- **债务奴**：无力偿债者卖身为奴。
- **出生为奴**：母奴所生之子，生而为奴。
- **亚人养殖**：亚人作为财产被买卖、养殖（以卡恩堡为代表）。
- **掠夺**：人口走私与掠夺（以尤西斯坦为代表，黑市奴贩贩卖亚人与奴工）。

### 奴隶身份

- 奴隶**没有期限，永生永世**为奴，除非赎身或解放。
- 奴隶**可以给自己赎身**：以积蓄或劳力换取自由。
- 奴隶的用途**主要看主人的想法**：家仆、矿奴、农作、豢养军医乐师、劳作苦役，全凭主人意愿。

### 亚人奴隶

亚人奴隶属于**财产，没有人权**，与牲畜同列。被买卖、养殖、驯养，是这个世界奴隶体系中最彻底物化的一环。艾西尼亚废奴并接纳解放奴隶，与卡恩堡的亚人养殖业形成尖锐对照。

### 解放渠道

- **赎身**：自己攒钱赎买自由。
- **逃跑**：逃亡（多逃往艾西尼亚）。
- **武力解放**：暴动、起义或被外力解救。
- **主人恩释**：主人恩典释放。

### 宗教态度

各国教会均**鼓励奴隶安分守己、不要反抗**，以教义将忍耐与服从神圣化——顺从主人是美德，反抗是罪愆。
