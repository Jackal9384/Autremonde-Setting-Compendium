# 第九章 魔物与冒险者

> 圣历 1810 年

## 一、魔物体系

### 魔物的定义

魔物是体内凝聚魔力核心的野兽或异形生物，与智慧种族（人类/精灵/矮人/魔族/亚人）有本质区别：魔物无法交流、不受文明约束，魔力已渗入其肉体本能。

### 四大来源

| 来源 | 成因 | 典型例子 |
|------|------|----------|
| 非聚合魔力粒子引导（最常见） | 游离于空气中的**非聚合魔力粒子**对野兽产生**正向引导作用**：魔源门植物密集区、矿脉裂隙、古代战场等魔力粒子弥散之地，野兽长期受其引导，体内魔力逐步沉淀、凝聚成核，异变为魔物。引导作用与魔力浓度正相关，浓度越高则异变越快、魔物越强，故魔物活动带与魔源门植物繁茂区高度重合 | 森林魔狼、矿洞蝙蝠、平原鬣狗群 |
| 亚人过兽化失控 | 兽化率＞85%，理智被兽性吞没 | 各地都有的"疯兽"，被村人视作魔物 |
| 先民迷宫遗存 | 先民时代势力封存的实验造物、失败实验体 | 地下迷宫的构造体、人工魔像、异形猎犬 |
| 污染/意外 | 魔法事故、炼金废料污染、被遗弃的法术造物 | 沼泽黏怪、酸蚀水母、变异的农田兽 |

### 等级体系（E至S，魔物威胁等级）

- **E级**：比野兽略强，农民可围猎。魔力皮毛有微薄价值
- **D级**：成群行动，村镇悬赏常客。普通民兵可对付
- **C级**：会本能魔法（喷火、毒雾、硬化皮肤），需专业队伍
- **B级**：小规模军队才能对抗，常盘踞一处为害
- **A级**：天灾级，往往与迷宫深层、魔力富集核心绑定
- **S级**：传说级，古书记载的灾厄，数百年一现

### 魔物价值（冒险者收入来源）

- **魔源核心**：魔物体内结晶，直接作魔源体使用，B级以上品质极高
- **魔力皮毛/骨材**：炼金与魔法材料，E级也有收购价
- **巢穴资源**：魔物巢穴往往长有魔源门植物或伴生矿

### 魔物生态

魔物活动与魔力浓度正相关：魔源门植物繁茂处魔物多；人类垦殖会压缩其领地，故边疆、荒地、深山、地下迷宫是魔物主要分布区。魔物不会主动攻击城镇，但会袭击商路与村庄，这正是冒险者需求的社会基础。

## 二、龙（特殊魔物）

龙是由鳄鱼变异而来的强大魔物，是魔物中的异数。与多数魔物不同，龙**具有智慧、会思考**，且存在历史极长，远早于人类文明。其变异起源已不可考，但先民时代的传说中已见龙的踪迹，先民迷宫与古代遗迹的壁画上亦留有龙的图样。

龙寿命极长，多数龙独居深山、大泽或迷宫深处，不轻易现身，亦不屑与低等魔物为伍。因其智慧与漫长历史，龙不受魔物等级体系的约束，最弱者亦在A级之上，传说中最古老的龙已近S级甚至超越之。屠龙是冒险者传说中的终极目标，但绝大多数屠龙故事只是酒馆里的吹嘘。

### 同源两支

龙的鳄鱼血脉在漫长的变异中分化出两个支系：

- **龙**：飞行支系，四足加双翼，翼展遮天，鳞片厚重、长吻利齿，背部棘刺沿脊延伸，栖息于高山、迷宫与荒原深处。是神话传说中的"真龙"，能飞，会魔法，是魔物顶点的象征。
- **鳄龙（沼龙）**：无翼支系，保留更多鳄鱼形态：粗壮低矮、四肢短而有力、长吻、厚重鳞甲、巨尾横扫，半水栖，潜伏于大河大泽与沼泽深处，伏击岸边的牲畜与人。被视为龙的近亲，民间有时将两者混称。

### 智慧与交流

龙有智慧、能思考、可记仇、会记恩，但**不会说"人话"**——龙之间以低沉的吼鸣与魔法传意交流，与智慧种族无法直接对话；仅极少数特殊的龙经漫长岁月习得人言，成为传说中能与人类交流的异数。

### 魔法能力

龙会魔法，是极其强大的魔物。龙的魔法源于其体内的魔力核心，随年龄与体量增长而愈发深不可测，吐息、御风、控水等皆是龙的看家本领。最古老的龙所掌握的魔法深度，连大法师也望尘莫及。

## 三、冒险者体系

### 起源

碎冠之战（1288-1773）结束，数十万退役佣兵流落各国，荒地与迷宫魔物滋生，各国默许民间自发讨伐，冒险者这一行当由此成型。至今约一代人，行业尚在磨合期。

**冒险者与佣兵一线之差**：两者同源于退役刀兵，都靠刀剑吃饭，区别只在雇主——佣兵以国家、贵族、商会为雇主，签契约为战，属军事外包；冒险者以散单为业，讨伐、护卫、探索，属治安外包。现实中彼此流动：冒险者攒出名气被贵族招揽成佣兵队长，佣兵淡季回来接散活，身份随时切换。

### 核心：名气即货币

**大部分国家没有明确的公会制度，冒险者主要靠自身打出名气。** 声望就是一切——战绩、口碑、名声决定能接什么活、拿多少钱：

- 无名小卒接低端散活：村子悬赏的野猪、商队的杂役护卫，报酬微薄
- 有名声者被贵族、商会亲自登门邀请，报酬按行情起价
- 真正的强者靠战绩说话：单挑魔物、护卫商队生还率、遗迹带出的战利品，皆是谈价的资本
- 吹牛者众：酒馆里的战绩十有八九是编的，真假全凭一桩桩实绩验证

### 行会的实际样貌（仅少数地区存在）

正规的"公会/行会"组织只在少数地区存在，且**只做中介与仲裁，不做评级认证**：

- 艾西尼亚的港口行会：登记、介绍活、调解纠纷、抽成
- 纳穆尔的魔法师协会挂名处：术师接活的平台
- 其余地区：冒险者自由接单，靠人脉与名气，无统一组织、无官方等级、无跨国档案

### 冒险者类型（按来源与风格）

- 职业冒险者：以此为业，靠任务与战利品维生
- 半路出家：退役兵、猎人、落魄骑士、还债的农奴
- 术师历练：魔法学院学生四处闯荡，赚材料与实战经验
- 雇佣兵兼差：战时受雇于国家，平时接散活

### 任务体系

- **悬赏讨伐**：村镇被魔物袭扰的悬赏，低端散活，多为野猪、狼群、D级魔物
- **商路护卫**：商队穿越荒地，按路程与危险程度议价
- **委托护卫**：贵族、教会、商会的指定委托，指名道姓请有名气者
- **迷宫探索**：先民迷宫清剿、遗迹取物（各国视迷宫为"灰色地带"，探索需自担风险，收获归探索者，各国抽成）

## 四、各国态度

尽管态度分化，各国统治者心照不宣地默许其存在：**零成本治安**（边疆魔物、商路盗匪由民间自发清剿，不花国库一分钱）、**失业缓冲**（消化退役兵、流民与破产农民，免得落草为寇）、**商会买单**（护卫报酬由商人出，国家白得商路安全）。风险在于这支力量没有忠诚度、可随时转向——故强权打压，弱国依赖，中间派边用边防。

| 国家 | 态度 |
|------|------|
| 艾西尼亚 | 扶持利用：无正规陆军，冒险者就是它的民兵体系，港口行会最规范 |
| 尤西斯坦 | 默许利用：与卫所军户重叠，征战时优先征召，等于免费预备役 |
| 纳穆尔 | 吸纳合作：魔法师协会与冒险者共生，术师历练场 |
| 卡恩堡 | 放任不管：领主各自豢养当私兵，行会名存实亡 |
| 奥列格 | 收编压制：怕民间武力威胁皇权，只许边境讨伐，迷宫归帝国封禁 |
| 达勒卡利亚 | 边缘化：国力衰微管不了，边区冒险者自生自灭，多为赏金猎人式的亡命徒 |
| 洪加利 | 局部雇佣：冒险者多被矿场主收编为矿场护卫 |
| 奎尔松 | 局部雇佣：冒险者从事矿脉魔物清剿，受矮人城邦雇佣 |
| 奥弗涅 | 混同共存：雇佣军文化发达，冒险者与佣兵界限模糊 |
| 阿格若 | 对立排斥：教会骑士团与冒险者对立，视之为异端散勇 |
| 松德高 | 取缔打击：几乎取缔冒险者（视为潜在武装威胁） |
| 伊普雷加利亚 | 不接受任何冒险者（拒绝外族） |
