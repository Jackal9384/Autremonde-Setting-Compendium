# 第七章 诸国志

> 圣历 1810 年

## 一、圣历总纲

圣历是世界通用的纪年体系，源自维拉帝国官方史官。其纪年起点追溯至先民时代的传说。自圣历元年至今，历史可分为七个阶段：

| 时代 | 年份 | 概要 |
|------|------|------|
| 先民时代 | 1-413 | 传说时代，数个割据势力并存，无大一统王朝，留下迷宫与实验造物 |
| 维拉建国-扩张 | 414-617 | 维拉王朝建立并扩张 |
| 维拉帝国时代 | 618-1101 | 精灵大一统王朝的鼎盛 |
| 叛乱时代 | 1102-1227 | 农民起义与魔法依赖拖垮精灵帝国 |
| 两级对立时代 | 1228-1287 | 维洛恩与奥列格两强对峙 |
| 纷争时代 | 1288-1773 | 碎冠之战，维洛恩裂为上百国，仅存六家 |
| 现代 | 1810 | 当前格局 |

## 二、历史沿革

### 先民时代（1-413，传说时代）

圣历元年的传说起点。先民时代并没有一个统一的大一统王朝，而是**数个割据势力并存**的乱世：精灵、矮人、魔族与人类的祖先部族散居于泰尔、诺尔、叙德三块大陆，以城邦、部族联盟与早期王国各据一方，相互征伐也相互通商。

先民时代的最大遗产是**迷宫与实验造物**。各势力为在乱世中争夺优势，纷纷押注魔法研究：以精灵的迷锁工坊、矮人的熔炉秘境与人类的炼金术士结社为代表的势力，在地下挖掘庞大迷宫作为研究据点与试验场，将魔法实验的成果——包括人造魔物、失控的法术造物与失败实验体——封存其中。先民时代结束时，这些迷宫与造物随势力的覆灭一并埋入地下，成为后世冒险者与探宝者的渊薮。维拉帝国的兴起与这些遗存并无直接传承，帝国对先民迷宫多采取封禁与收编的态度，但迷宫内的魔物与实验造物却成为魔物体系中"遗迹魔物"一系的源头。

### 维拉帝国（世界第一个大一统王朝，精灵帝国）

维拉帝国是这个世界第一个也是迄今唯一真正意义上统一主大陆的大一统王朝，由精灵建立，发源于两河流域（白河与青河），故都位于泰尔大陆中东部。在先民时代的乱世余烬上，圣历414年维拉王朝建立，历经两百年扩张（414-617），将泰尔大陆的广袤疆土乃至诺尔大陆的边疆纳入治下，于618年进入帝国时代。

维拉帝国是精灵文明的巅峰。七贤者自异世界降临，为其带来了成文法典、驿道系统、常备军团、双族共治框架、大地法系理论与实践。圣教由精灵创立、七贤者确认正统，成为帝国的精神支柱。帝国魔法学院保存了最完整的大地法系传承，魔法成为帝国社会的骨架。

**人类的地位**：在维拉帝国，人类是低等存在，很多时候被当作奴隶或下等劳工。即便在帝国境内（诺尔大陆除外）混到最高处，人类也只是中等贵族，永远够不到上等贵族的门槛。诺尔大陆是人类故土，但与泰尔大陆的精灵贵族相比，诺尔人类始终被视为边鄙之民。七贤者是人类出身，却被精灵帝国尊为无上的贤者，是帝国对人类唯一的破例。

**防卫外包与维拉崩解的祸根**：精灵繁衍困难，人口长期不足，帝国庞大的疆域无法由精灵亲自戍守。因此，帝国的防卫工作从一开始就外包给人类：边境与行省由人类佣兵军团驻防，后期随着疆域扩张，连核心领土的守卫也大量改用人类战士。这些人类战士操持着帝国的刀剑，也日渐摸清了帝国权力结构的底细——正是他们后来篡夺王权的本钱。

**崩溃原因**：维拉帝国的崩溃源于内部的农民起义与对魔法的过度依赖。精灵贵族将魔法固化进社会运行的一切环节，人类与底层各族承担着供养魔法社会的沉重负担，长期积压的怨愤在圣历1102年爆发为席卷帝国的农民起义，帝国中枢在连年镇压中耗尽国力，最终在叛乱时代（1102-1227）分崩离析。

**分裂结果**：维拉崩溃后，其疆土裂为两大继承势力：
- **故土（主要核心控制区）**：两河流域、泰尔大陆中东部核心地带，由人类中层贵族趁乱篡夺王权，建立**奥列格帝国**，承认维拉正统地位，承袭故都与圣历官。
- **边疆控制区**：诺尔大陆广大边疆地带，成为**维洛恩帝国**，由戍边的蛮族佣兵趁乱建国。

### 维洛恩帝国（东罗马）

维洛恩帝国源自维拉在诺尔大陆的边疆控制区，本是人类故土的蛮荒之地。所谓蛮子并非异族，而是人类：维拉帝国因精灵繁衍困难、兵源不足，将防卫工作外包给人类，诺尔殖民地的人类部落勇士被大批招募为佣兵戍边。

维拉在诺尔实行公国制度：这些公国本身就是雇佣军，公国统治者既是帝国册封的贵族，也是统率人类佣兵军团的军阀头目。维拉崩溃之际，驻边的蛮族佣兵首领趁乱而起，最终由实力最强的蛮酋登位为帝，建立以人类为主体的帝国，于两级对立时代（1228-1287）与奥列格帝国形成两强对峙的格局。

维洛恩**不承认维拉的正统**。在维洛恩的历史叙事中，维拉帝国不过是历史长河中的一段插曲，其法统早已随其崩溃而断绝。维洛恩**只承认圣教的正统**，并由此推行一套"指鹿为马"式的宗教改造，宣称圣教的真义早在维拉时代就被尘世政权玷污，唯有维洛恩人才是圣教神谕的真正继承者。维洛恩自行篡改出人类化的教义与礼仪，其自创的圣教体系由驻跸圣城的大主教执掌，与奥列格境内驻跸维拉故都的正牌总主教分庭抗礼。

帝国境内精灵与亚人地位低，**不排斥魔族**：魔族与人类同源，边境与叙德大陆隔海通商，魔族商人、佣兵与工匠在西部各地并不罕见。这种"重人类、轻精灵亚人、容魔族"的独特态度，成为维洛恩区别于奥列格的文化底色。

**碎冠之战**：圣历1288年，维洛恩帝国帝位继承争端激化，诸侯叛乱四起，帝国进入纷争时代（1288-1773）。数百年的碎冠之战中，维洛恩裂为上百个国家。至圣历1773年，战乱尘埃落定，上百个国家只剩六个最终赢家：达勒卡利亚、尤西斯坦、阿卡迪奥斯、卡恩堡、艾西尼亚、纳穆尔。六国仍互认维洛恩法统，皇帝虚位悬置至今。六国之中，达勒卡利亚神权国为维洛恩的直系继承者，承袭其帝号、法统与圣教中枢地位。

## 三、诺尔大陆西部六国

六国原为维洛恩帝国诸侯，据守人类的故土诺尔大陆，经碎冠之战成为最终赢家。北境大陆的甲胄以**板甲衣与锁子甲**为主——比魔大陆的札甲锁子甲精良，却不及奥列格独家掌握的全套板甲，处于三者之间的中间水平。

### 达勒卡利亚神权国

> 原型：拜占庭帝国（科穆宁至安格洛斯时期）｜定位：维洛恩直系继承者，圣教正统自居，双头共治神权国，西陆衰落的昔日强权

**概况**：位于诺尔大陆西北角，维洛恩帝国的直系继承者，辖28行省（原72省，1793-1801年战败丢失44省）。圣城三重城墙环绕，内城为皇宫与圣教大主教座堂所在，是诺尔大陆现存最古老且从未中断定居的都城之一。圣冕帝皇与大主教构成双头共治。昔日的西陆号令者，经1793-1801年战败后仅存圣城故都与西北角的残余疆土，国土相连、再无飞地，国力衰微，靠圣教威望与外交权谋在强邻夹缝中喘息。

**地形与气候**：核心疆域为圣城周边山地向西北延伸至海岸的一片连续国土。境内多山地丘陵，气候偏凉，森林覆盖率高，耕地零碎。地形易守难攻，也造就了困守一隅的保守性格。失去的44省多为东南部与南部的平原沃土，残留的28省以山地为主，农业更为贫瘠。

**农业与经济**：山区土质贫瘠，农业仅足自给，以燕麦、黑麦为主，猪、牛为主要畜牧动物。经济支柱为圣城税收、教产贡赋与过境贸易——圣城地处两河支流与近海航路节点，是诺尔西岸与叙德大陆贸易的中转站。战败后国土萎缩、税基塌缩，上层贵族却依旧奢华无度。为填平贵族享乐的窟窿，朝廷**连年加税**：宗教税、国家税、领主税三税之外，又增战争税、重建税、军粮征购等名目，税吏下乡如蝗虫过境，农户不堪重负，逃亡者众，土地抛荒又令税基进一步萎缩——恶性循环之下，朝廷只能再次加税，百姓民不聊生。

**贵族势力与政治**：双头共治——皇帝自居维洛恩神圣帝号的唯一合法继承者，实际统治范围仅限圣城周边；大主教掌教权，二者相互牵制。贵族以赐福者与宦官为两大支柱：赐福者世代蒙受圣教福荫，把持魔法学院、教会要职与朝堂高位；宦官掌管内廷与密报，虽出身低贱却凭皇权信任握有实权，常在皇位更迭中充当操盘者。封地贵族集中于圣城周边，受朝廷直接辖制。官僚体系承袭维拉旧制，职位多可售卖，吏治腐败。宫廷礼仪极其繁复，以通晓古精灵语为教养标志。

**军事**：锁子甲与板甲衣为主，具装骑兵几乎损失殆尽——仅少量驻守王城的得以幸存，步兵没有重装可用。领主骑士-佣兵制，以领主骑士为骨干，辅以雇佣兵补充，缺乏统一常备力量。残余海军尚可维持过境护航与基本海防。

**宗教与文化**：圣城大教堂是维洛恩自创圣教体系的精神中枢，内藏据称属七贤者的圣物。宫廷与教会礼仪之繁复冠绝大陆。受邻居艾西尼亚影响，境内各种族相对平等——精灵、亚人与魔族在此的处境较其他诸国宽松，歧视相对和缓。

**对外关系**：1793年遭阿卡迪奥斯与卡恩堡夹击，1801年停战时被吞超六成领土，被迫签订**不平等条约**：割地之外，还须支付巨额战争赔款，阿卡迪奥斯军队获准在达勒卡利亚境内驻防，商税与过境关税受两国监督分成，教会什一税的上缴对象也由两国瓜分监督。名义上仍是六国共尊的教廷之首，实际上国门洞开、主权残破，靠宗教权威与挑拨离间维持弱势中的体面。

### 尤西斯坦联盟

> 原型：早期英格兰（诺曼至金雀花早期）｜定位：连接北境与主大陆的巨大陆路地带，四面环海，议会架空君主，资本与血统对撞的新兴国家

**概况**：地处链接诺尔大陆与泰尔大陆的巨大陆路地带，四面环海，扼守沟通两块大陆的陆上通道与海路门户，辖18行省。北境邻阿卡迪奥斯王国，东路邻奥列格帝国。议会已架空君主，实权落入贵族与新兴商人组成的议会之手。资本与血统之间的对抗不可避免，议会内部按此分野分成两大阵营。

**地形与气候**：地形以缓丘与河谷为主，国土城堡林立，城堡构成控制土地、人口与要道的核心节点，都城为王冠堡垒所在。四面环海，温带海洋性气候，温和湿润、四季分明。

**农业与经济**：草场广布，农牧并重，以小麦、海产牛羊为主，是西陆少见的粮畜自足之地。农牧业与过境贸易为经济基础，高原畜牧产出羊毛与牲畜，羊毛贸易催生富商。扼守两大陆通道的地位带来丰厚商税。航运与商业极为发达，海陆商路在此交汇。繁荣之下暗影滋生：人口走私与人口买卖兴盛，黑市奴贩与掮客在港口间游走，贩卖亚人与奴工。

**贵族势力与政治**：国王名义上仍是元首，实权落入议会之手。教会控制的司法正被商业契约逐步替代，土地正被议会逐案转为可交易资产。贵族分新旧两系：旧系是拥地自重的血统贵族，靠城堡、庄园与骑士家臣立身，抱团把持各郡的封建司法与兵权；新系是凭商船与账册起家的商人贵族，以金钱购入爵位与地权，盘踞港口与议会。两系在议会中缠斗不休。

**军事**：盛产挽马，却不适宜骑兵作战，基本只有轻骑兵与步兵，另有少量走私来的老式韦礼安式板甲（哥特式）；步兵披甲率＞75%、具装＜20%。以长弓手与半职业化军队著称。半职业化军队类似卫所制——军户屯田自给、平时耕作、轮班操练，战时应征出征，介于民兵与职业兵之间。海军承担护航与收过路费的职能。

**宗教与文化**：信仰圣教圣公宗，教会长期掌控司法与教育。贵族崇尚骑士精神与血统谱系，商人文化以契约、账册与实用主义为底色。外交务实而少宗教狂热，在两大陆强邻之间左右逢源。

### 阿卡迪奥斯王国

> 原型：普鲁士（军国主义）｜定位：诺尔大陆西部疆域辽阔的军国，西陆六国现存实力最强、疆域最大，最强陆军，容克军官集团

**概况**：位于诺尔大陆西部，西陆六国中实力最强、疆域最大，辖63行省（碎冠之战前34省，1793-1801年吞并达勒卡利亚29省扩张而来）。国王大权在握，军国主义立国，大陆最强陆军。名义上仍奉达勒卡利亚大主教为教廷之首、加冕须经其手，但教会什一税已收不上来，司法权逐步收归王室。圣历1774年铁血宰相上台后快速崛起，1793-1801年夹击达勒卡利亚吞其过半领土，跃居西陆霸主。

**地形与气候**：以广袤平原与缓丘为主，高地干冷气候，冬季寒冷、夏季燥热。疆域虽大，地力却因连年征战与过度开垦而日渐贫瘠。

**农业与经济**：主要种植黑麦类作物，西部牧场连片，牧马养畜为业。经济重心服务于军事，军工与军需产业优先。连年战争使土地大面积荒芜，田园凋敝。近年靠战利品与赔款缓解国内压力，但治标不治本。农民受王室税、军税和领主税多重压榨。

**贵族势力与政治**：中央集权程度大陆诸国之最，王室直辖领地占全国约四成。贵族阶层以容克地主和军官集团为主，土地与军功深度绑定，历代国王持续收回分封土地以供养常备军。贵族子弟以从军为第一选择。底层百姓几乎没有上升空间，参军是唯一的出路——军功晋升通道吸纳平民精锐，也把一代代青壮送上战场。

**军事**：具装骑兵以乌兰骑兵为主，身披板甲衣；步兵披甲率＞60%、具装＞30%，步兵以刀盾为主。常备军规模庞大、纪律严明，是大陆最职业化的陆军。军事采取军人职业化路线：士兵以当兵为业，长期服役，严格训练，完善后勤，是西陆唯一真正意义上的职业军队。军官主要由容克贵族担任，军功晋升通道吸引平民精锐。

**宗教与文化**：尚武文化浓烈，军功与荣誉高于一切。名义尊奉圣公宗，教权已被王权逐步侵蚀。

### 卡恩堡公国

> 原型：中古法兰西封建领主制｜定位：诺尔大陆西南沿海典型封建领主制国家，标准中世纪农业国，大公名义最高领主

**概况**：位于诺尔大陆西南沿海，辖32行省（原17省，1793-1801年吞并达勒卡利亚15省扩张而来）。典型的封建领主制国家，大公名义上为最高领主，实权分掌于各级封臣手中，采邑层层分封，领主与附庸以效忠与封地维系。封建碎片化农业国，国力中等。

**地形与气候**：以平原与丘陵为主，沿海有狭长沃野。气候温和湿润，适合农耕。

**农业与经济**：标准的中世纪庄园农业，村落、磨坊、教堂与领主宅邸构成基本单元，封建领地的自给自足是经济底色。以小麦、牛、绵羊为主的农牧格局，葡萄与亚麻为经济作物，葡萄酒与亚麻布为名产。虽有沿海商港便利，内部却关卡林立、商税层层盘剥。亚人商业发达——亚人的买卖、养殖产业兴盛，亚人奴隶与驯养兽的贸易颇具规模，是公国财政的重要来源。

**贵族势力与政治**：四方领主及其麾下的骑士团是立国之本。领主在其领地内拥有近乎完整的司法、征税与军事权，同一行为在相邻领地法律后果完全不同。常年战乱，农民不知道明天谁收税。三家大国（阿卡迪奥斯、艾西尼亚、纳穆尔）的相互忌惮是它存活至今的真正原因。

**军事**：具装骑兵较少，以锁子甲、刀盾为主，更倾向于步兵上马；步兵披甲率＞70%、具装＜25%，步兵以刀/斧盾为主。领主骑士制，作战以各领主的骑士团与私兵为主力，缺乏统一指挥，防御优于进攻。

**宗教与文化**：宗教压迫严重，各地领主各自豢养异端审判官。圣教公理派在此有相当追随者。

**对外关系**：一直敌视艾西尼亚——艾西尼亚废除奴隶制等于挖卡恩堡亚人贸易的墙角，边境摩擦不断。1793年与阿卡迪奥斯联合夹击达勒卡利亚，吞约10%领土后于1801年先行停战。

### 艾西尼亚联盟

> 原型：荷兰（低地农牧国）｜定位：诺尔大陆西南半岛的亚人联邦，农牧发达但缺矿产，贸易金融驱动，西陆金融心脏，多族混居中立枢纽

**概况**：位于诺尔大陆西南半岛，辖8行省。金秤议会由掌控庞大商业网络的商会巨头把持，凭借贸易与金融而非矿产立国，是西陆金融心脏。亚人联邦——唯一提倡种族平等与解放奴隶制的国家，亚人拥有完整公民身份，在政治中举足轻重。凭借金钱而非刀剑立国，在西部诸国的相互倾轧中保持超然中立。

**地形与气候**：低地平野、水网纵横，地形以低地沼泽与圩田为主，人们筑堤排水、围垦造田。气候温凉湿润、海风长吹。几乎不产矿产。

**农业与经济**：农牧业发达，以小麦、牛、绵羊为主，乳制品尤为兴旺，乳酪与牛群为名产。**唯一横跨大洋直通叙德大陆的国家**，大洋航线终点抵奎尔松与松德高港口，这条独占地利的海路是其富庶的源泉。西陆最开放的多族混居商业枢纽，亚人、魔族与矮人商人可在此合法定居经商。**世界唯一废除奴隶制的国家**，接纳被解放的奴隶，是大陆奴隶逃亡与解放的灯塔。

**贵族势力与政治**：金秤议会由商会巨头把持，政治以商业利益为驱动。亚人占人口约30%，在议会中占有席位，人类约40%，其余种族约30%。中立地位使其成为西部通往外界的贸易门户与情报集散地。

**军事**：轻甲为主，少量进口奎尔松的克尔式板甲（仿韦礼安式的半身甲）；本土不产马匹，基本没有骑兵。不设常备陆军，以专职军人组成的城邦卫队、雇佣兵与海军商船护航体系维持防御。

**宗教与文化**：多族混居带来宗教宽容，无国教，商业契约精神高于教条。文化开放务实。

### 纳穆尔王国

> 原型：神罗晚期的诸侯联邦｜定位：诺尔大陆南部沿海松散贵族联邦，国王仅为礼仪象征，七大公爵实际统治

**概况**：位于诺尔大陆南部沿海，辖16行省，松散的贵族联邦体制，国王仅为礼仪象征，七大公爵实际统治。与叙德大陆隔海相望，商路往来密切。国内相对安定，魔法发达。随着达勒卡利亚魔法学院凋零，**已继承其地位成为西陆魔法传承的新中心**，各国术师慕名而来。

**地形与气候**：以沿海平原与内地丘陵为主，南临温暖海流，干旱稀疏灌木气候，类似于意大利西西里一带，是六国中物产较为丰裕者。

**农业与经济**：稻麦与果蔬皆宜，沿海渔业发达。经济以沿海港口贸易与海洋渔业为主，与叙德大陆跨海商路是经济命脉。与伊普雷加利亚长岛时常通商，香料、魔法植物与奥弗涅珍奇在此交易流通。魔法工坊与法器贸易繁荣。

**贵族势力与政治**：七大公爵为实际统治者，各在其领地内自行收税立法、保有私兵。联邦会议协调共同事务，国王由七大公爵推举产生，仅具礼仪权威。

**军事**：札甲与锁子甲混装，轻骑兵为主、擅长马上射击；步兵披甲率＞60%、具装＞15%。佣兵与政府军制（府兵制）——各公国既有地方卫所、平时耕作战时出征的府兵，也雇佣专业佣兵补足战力，两者并存，由联邦会议统筹协调。缺乏统一指挥。

**宗教与文化**：信仰相对宽松，各族混居通商，文化受叙德大陆与伊普雷加利亚影响，兼有魔法研究的学术传统。

**对外关系**：奉行平衡术，在诺尔大陆诸国与叙德大陆势力之间左右逢源。

## 四、泰尔大陆中东部

### 奥列格帝国

> 原型：法兰西（波旁王朝时期的中央集权君主制）｜定位：人类中层贵族篡夺王权建立的帝国，承认维拉正统，泰尔大陆独占，大陆版图最大帝国

**概况**：位于泰尔大陆中东部，大陆版图最大的帝国，辖94行省。维拉崩溃后，人类中层贵族趁乱夺权，建立奥列格帝国，**承认维拉正统**，承袭故都与圣历体系，以维拉继业者自居。疆域坐拥两河冲积平原的膏腴之地，是世界的粮仓。中央集权程度极高，皇权独大。

**地形与气候**：北缘抵伊斯菲尔山脉，南境至地中海式海岸，腹地丘陵平野相接。气候适宜，水网盘踞两河冲积平原，中北部为温带半干旱高原，南岸沿海为地中海式气候。

**农业与经济**：麦浪与葡萄园绵延千里，农牧皆盛。水网灌溉之下主要种植小麦类作物，畜牧发达。农业及其附加税是帝国经济的重要来源。凭借宗教影响与政治外交手段，不断**收割叙德大陆与诺尔大陆的财富**——以圣教教权干涉诸国内政、以贸易与债务输出控制其经济命脉，将两大陆的资源与财富源源吸回帝国。

**贵族势力与政治**：皇权独大，官僚体系庞大。帝国境内领主、宗教与国王**三方各有私兵**：领主的领地私兵与教廷的教团卫队并立，与皇家的禁卫军团、各皇子的地方私兵互相牵制。每次皇帝驾崩伴随一轮宫廷清洗，随后迅速恢复对外扩张。贵族竞相攀附精灵血统——受精灵千年统治的审美影响，黑发蓝眼黑眼被视为高贵，七贤者的后代多为混血。

**军事**：以强力的新式板甲具装重骑兵闻名——马上冲锋能击穿敌军阵型，下马作战如同人形高达；步兵披甲率＞90%、具装＞50%，劲弩替代弓。魔力水平高，完整继承维拉的大地法系魔法传承，帝国魔法学院系统延续不断，施法者阶层庞大，是泰尔大陆的魔法强权。**全身板甲（格里尔式/米兰式）锻造技术为奥列格独家掌握**，泰尔大陆之外无人能造，且金属锭需在帝国腹地加工方能成形——这是帝国铁骑的技术壁垒。

**宗教与文化**：圣教占极高社会占比，君权神授、皇帝为圣教最高护法，王权与教权深度绑定。教皇（教长）在世俗事务上权力较少，却握有**册封正统的权利**——历代皇帝登基须经教长加冕。宗教拥有单独领地、领民与税收权。种族上排斥精灵亚人魔族——魔族与亚人受严重歧视，非信众交额外人头税；对精灵排斥相对较少，精灵贵族仍保有尊崇。

### 阿格若神权国

> 原型：教皇国｜定位：奥列格境内国中国，教皇（教长）驻跸地，掌册封正统权，教权凌驾王权

**概况**：位于奥列格帝国腹地，教皇（教长）的所在地，帝国境内的国中国，辖6行省。教长由教廷枢机推举产生，与皇帝分掌教俗两权。**在这6郡之内教皇的权力大于国王。**

**地形与气候**：位于泰尔大陆南岸地中海沿岸，丘陵地形，气候为地中海式——夏季干热、冬季温雨。

**农业与经济**：教区土地肥沃，葡萄与橄榄种植兴盛，教产收入充裕。领地、领民与税收权完全自洽。

**贵族势力与政治**：宗教贵族（枢机主教团）为统治核心，教长由枢机推举。在这6郡之内教权凌驾王权，皇帝法令在教区形同虚设。历代皇帝登基须经教长加冕——册封正统是教皇对帝国最致命的筹码。

**军事**：有三个超千人规模的大型宗教骑士团，是教廷武装的骨干。

### 洪加利共和国

> 原型：法兰西第一共和国｜定位：奥列格东境商人革命建立的早期资本共和国，行会联合议会，泰尔大陆东缘工业基地

**概况**：位于奥列格帝国东侧，辖16行省。此地原为帝国东缘驻地，驻守于此的中等贵族与本地商人私通，圣历1773年不满苛税与垄断，发动叛乱脱离奥列格帝国建立共和国。与尤西斯坦地位相当，同为商人革命建立的早期资本共和政体。此地原本就是奴隶较多的混居地区——各族奴隶在此开采劳役，人类、魔族与亚人杂处。

**地形与气候**：位于泰尔大陆东缘，多山地，两条山脉纵贯，不适宜骑兵作战，气候受海洋调节，温和湿润。

**农业与经济**：以大麦与山羊、猪为主的农牧格局。两条山脉是泰尔大陆内重要的工业基地——**只负责开采原矿与冶炼**，矿脉与冶炉高度聚集，产出大量金属锭。然而为了格里尔式（米兰式）全身板甲锻造方式的保密，金属锭一律运往帝国腹地进行加工，洪加利境内不见任何板甲锻坊。仅有**两座港口**：一座北方深水港，一座对叙德贸易的不冻港。这第二座港口的建立，分去了奥列格对叙德贸易港的一半份额——洪加利凭此与奥列格分据萨塔什海峡航路，对叙德的跨海贸易是其经济命脉之一。掌控帝国东缘的商路，贸易与商业金融为经济命脉。

**贵族势力与政治**：政体为行会联合议会，各大商行轮流主导国政，矿冶大商与港商行会在此最有话语权。内部派系斗争剧烈——激进派、温和派与亲帝国复辟势力反复博弈，政变与清洗循环往复。

**军事**：多山地，不适宜骑兵作战，以重装方阵步兵为主，装备老式韦礼安式板甲，步兵披甲率＝具装率＞70%，剑盾弩为主。

**对外关系**：与叙德大陆的松德高暗通款曲——松德高在奥列格与洪加利之间撺掇挑拨，乐见帝国东缘生乱，借洪加利牵制奥列格，洪加利也借叙德航路与松德高互相利用。

## 五、叙德大陆（魔大陆）

### 奎尔松王国

> 原型：中东城邦｜定位：叙德大陆北部山脉上的锻造之国，矮人核心故土，与魔族混居

**概况**：位于叙德大陆北部，辖8行省，山脉上的锻造之国。矮人建立王国，是矮人文明的核心故土与政治中心，地表城邦由矮人主导治理；大量魔族部落散居山麓与荒漠之间，形成矮人与魔族混居格局。

**地形与气候**：山峦起伏，城邦依矿脉而建。高原山地气候，海拔高、寒冷干燥。

**农业与经济**：以稻米、山羊、猪、羊驼为主的农牧，豆制品是重要的蛋白质来源；以矿脉开采与金属锻造立国。地心熔炉技术发源于此，秘银精金提纯为全大陆垄断，山间炉火昼夜不息，全大陆最精良的兵刃与甲胄皆出于此。魔大陆甲胄以札甲与锁子甲为主，奎尔松也未能掌握全身板甲技术。

**军事**：基本都是高山丘陵，没有骑兵，全军皆为身披半身板甲的重装步兵，配合矮人强悍的身体素质基本等于无敌。

**对外关系**：与松德高既合作又竞争，共同把持叙德大陆。不敢开罪奥列格，但保持一定距离。

### 松德高王国

> 原型：突厥-奥斯曼（土耳其）｜定位：叙德大陆中部高原王国，纯魔族国家，采石与矿业立国，尚武，怀统一魔大陆的野心

**概况**：位于叙德大陆中部，辖40行省，纯魔族国家，矮人在此占比很少，统治、人口与文化皆以魔族为主体。怀有统一魔大陆的野心，却被死死按在叙德大陆内部。

**地形与气候**：高原与山地地形，气候干旱少雨，绿洲与台地交错。

**农业与经济**：以稻米与燕麦为主，海边吃鱼，内陆主要蓄养山羊。农业勉强支撑国民生活，主食自给有余而丰裕不足。经济主要靠采石场与矿石开采——大理石、花岗岩等石料与各类矿石源源不断运出。以矿冶与骑兵立国。

**军事**：具装骑兵较少，以札甲、刀剑冲锋掠袭为主；步兵披甲率＞80%、具装＞60%，以枪矛方阵步兵为主。尚武。但打不过奥列格，也不敢得罪奎尔松（自断军备来源）。

**对外关系**：与奎尔松在合作与竞争之间小心周旋，共同把持魔大陆。

### 奥弗涅王国

> 原型：南方神权王国｜定位：叙德大陆最南端人类王国，大陆极南端唯一丰硕之地，冲积平原与畜牧地广布

**概况**：位于叙德大陆最南端，辖6行省，大陆极南端的唯一丰硕之地。王室自称海洋女神后裔，崇拜海洋与风暴之神。丰饶的物产加之独步的航海术，使奥弗涅成为叙德大陆最富庶的粮仓与商埠。

**地形与气候**：大片冲积平原沃野千里，水草丰茂的畜牧地广布，与魔大陆普遍的贫瘠地貌形成鲜明对比。气候温润，降水充沛。

**农业与经济**：叙德少数适合畜牧与稻、麦种植的区域，冲积平原农业发达，畜牧兴旺，是叙德大陆的粮仓。濒临南方风暴海域，航海技术独步南方，巨型沙舟与破浪船往来于沿海诸港。与伊普雷加利亚长岛隔海相望，时有通商。

**军事**：依靠魔法与雇佣奎尔松与艾西尼亚的雇佣军保证国家安全，自身军力有限。

## 六、南方海域

### 伊普雷加利亚王国

> 原型：精灵王国｜定位：南方海域纯血精灵王国，格雷米奥修会唯一信仰地，精灵文明正统的最后孤岛

**概况**：南方海域一块从西至东分布的整块细条状岛屿，辖4行省，纯血精灵王国，格雷米奥修会唯一信仰地，精灵文明正统的最后孤岛。王室以血统纯正自居，以"精灵正统唯一继承者"自许，与泰尔大陆精灵若即若离。

**地形与气候**：长岛呈西高东低走向，西段火山台地林立，东段渐趋平缓，环礁与泻湖点缀于海岸。植被繁茂，气候湿润，多火山与台地，森林几乎覆盖全境，终年温和多雨。王都伊兰黛坐落于岛中段北岸的火山台地上，三面环林、一面临海。

**农业与经济**：热带-亚热带饮食，以香料、魔法植物、稀有木材与法系产物出口为主，换取粮食、金属与岛上缺乏的物资。贸易对象以纳穆尔最为密切，与奥弗涅亦通有无。精灵对商贸态度审慎，只收必要物资，无意卷入大陆政治与战争。

**贵族势力与政治**：王室之下设长老议会，由各支老贤者与格雷米奥修会的修道院长组成，共议国事。王位世袭，但继承需经长老议会与修道院长共同认可。外族（人类、亚人、魔族）被严格限制入境定居，仅许贸易商旅短暂停留。

**军事**：以轻步兵为主，辅以少量轻骑兵。无大规模常备军，亦无扩张欲望。防御依赖三重屏障——外海风暴洋的天然险阻、森林法系结界、精灵术师精锐卫队。海军为小型巡逻舰队。

**宗教与文化**：格雷米奥修会是国教，精灵古礼完整保存——古精灵语经文、圣咏、仪式一字不改，是维拉帝国时期圣教最初面貌的活化石。精灵以黑发蓝眼、黑眼为高贵血统的象征。文化保守而骄傲，视主大陆精灵为血统败坏的远亲。

**对外关系**：奉行孤立与警惕。对纳穆尔保持友好通商，对奥弗涅互有往来但保持距离，对奥列格及其他强国警惕其觊觎，拒绝任何势力染指长岛。

## 七、分封制度

### 总纲

世界的封建诸国普遍实行**分封制**：君主（皇帝/国王/大公）将土地与人民分封给贵族，贵族以效忠、兵役与贡赋作为回报。分封的实质是以土地换忠诚。除洪加利（共和国）与艾西尼亚（商人议会制）外，诸国皆为分封体系。

**分封链条**：君主→直属封臣（大贵族）→次级封臣（中小贵族）→骑士，层层隶属。越级效忠被普遍禁止（"我的附庸的附庸，不是我的附庸"在诺尔大陆西部通行，奥列格则因皇权集权而弱化此规则）。

**封地义务**：领主对封地负有治理、征税、司法与军事征召之责；对上级负有效忠、纳贡（定额或年贡）、出兵（按封地规模出兵役）之责。拖欠兵役或反叛即丧失封地。

### 爵位体系

| 爵位 | 地位 | 说明 |
|------|------|------|
| 皇帝/国王/大公 | 君主 | 仅一人，分封体系的顶点 |
| 公爵 | 最高级封臣 | 往往辖数省，权倾一方（纳穆尔七大公爵、奥列格公爵） |
| 侯爵 | 高级封臣 | 边防重臣，多驻守边境要地 |
| 伯爵 | 中级封臣 | 诸国封臣的主体，辖一郡或数县 |
| 子爵 | 次级封臣 | 多为伯爵副手或主教代理 |
| 男爵 | 低级封臣 | 小领主，拥有庄园与少量骑士 |
| 骑士 | 贵族最末一级 | 无封地者称"单骑"骑士，有封地者称"封地骑士" |

**虚衔与实封**：爵位分"实封"（有领地的爵位）与"虚衔"（荣誉爵位，无封地）。虚衔多为君主收买人心或奖励军功所授，有荣誉无实权。

### 封地运作

- **采邑**：封地的核心单位。领主直辖部分称"直领地"，其余分封给下属；直领地收入是领主的主要财源。
- **庄园**：封地的基层生产单元——村落、磨坊、教堂与领主宅邸构成基本格局，领主对庄园内的农奴与佃户拥有征税与司法权。
- **兵役**：封地按规模承担兵役义务，骑士以个人服役（自带马匹装备）折算封地，领主按需征召。
- **转封与没收**：未经上级同意不得转让或转封封地；谋反、怠于兵役、绝嗣无继承者时，封地收归上级。

### 继承制度

- **主流：长子继承**——封地与爵位由长子（或长系男性后裔）整体继承。此制在奥列格、卡恩堡、达勒卡利亚、尤西斯坦（旧贵族系）通行。
- **均分制**：部分地区实行诸子均分（卡恩堡部分领地、纳穆尔部分公国），是封建碎片化的推手之一。
- **选举制**：少数领地由领主议会选举产生（阿格若教长由枢机推举、纳穆尔国王由七大公爵推举）。
- **女性继承**：各国普遍限制女性继承——无男性后裔时，女儿可继承（经由丈夫代行），或封地由旁系男性继承。奥列格因审美与血统崇拜，对女性继承的限制最严。

### 各国分封差异

| 国家 | 分封特征 |
|------|---------|
| 奥列格 | 皇权集权下的分封：官僚体系与封臣并行，皇帝直辖行省约占大半；封臣有领地私兵，但受宫廷清洗与军权收夺双重钳制 |
| 阿卡迪奥斯 | 土地与军功绑定：容克地主即军官集团，历代国王持续收回分封土地供养常备军，王室直辖约占四成 |
| 卡恩堡 | 最典型封建分封：四方领主层层分封，领主在领地内拥有近乎完整的司法、征税与军事权，分封碎片化最严重 |
| 达勒卡利亚 | 赐福者世家垄断封地，封地贵族集中于圣城周边；战败后大量封地被阿卡迪奥斯与卡恩堡夺取 |
| 尤西斯坦 | 旧贵族保有传统封地；新贵族（商人）以金钱购得爵位与地权，封地开始商品化 |
| 纳穆尔 | 七大公爵各辖一方，联邦制下分封即"自治"——公爵在其领地内自行收税立法保有私兵 |
| 艾西尼亚 | 无分封：金秤议会商人掌权，土地为可交易资产 |
| 洪加利 | 无分封：共和国，废除贵族特权 |
| 奎尔松 | 矮人城邦制：城邦主（长老）分掌矿脉与城邦，近似贵族联合体 |
| 松德高 | 军事贵族分封：骑兵贵族（贝伊）领有封地，以兵役换取土地 |
| 奥弗涅 | 王室直辖为主，分封较轻，贵族多为王室旁支 |
| 阿格若 | 教区制：枢机主教分掌6郡教区，属教廷分封 |
| 伊普雷加利亚 | 无世俗分封：王室直辖全岛，长老议会共议国事 |

## 八、全球性规则

- **精灵人对应罗马人**，黑发蓝眼、黑眼被视为高贵的象征（详见第三章《种族》）。
- **全球性规则：除艾西尼亚外，奴隶贸易在本世界全部合法。** 仅艾西尼亚废除奴隶制，接纳解放的奴隶；其余诸国的奴隶买卖均受法律承认，卡恩堡的亚人买卖、尤西斯坦的人口走私即属此类（详见第八章《社会与生活》）。
